# Sentetik muhasebe örneği

protocol.json ve measurements.jsonl eğitim/kullanım örneğidir; gerçek model, repo, invoice veya independent evaluator çalışması değildir. Digest değerleri sentetik etiketlerden türetilmiştir. 2 arm × 3 task × 3 repeat = 18 assignment vardır; yalnız primary repeat için 6 satır verilmiştir. Diğer 12 koşu missing olarak paydada kalmalıdır. Her arm'ın iki solution ve ayrı SAFE_BLOCK kontrolü bulunur. Başarısız solution üç retry toplamını tutar; yerel CPU/index/insan rework ölçümleri bilinmiyor.

Root README ve [değerlendirme kılavuzu](../../docs/EVALUATION.md) komutları anlatır. Imported metadata false release/adoption flags taşır; sentetik örnek ürün üstünlüğü kanıtı olarak kullanılmaz.
