# ADR 0007 — Typed single-worker plan and declared-local runtime

Status: Accepted for 0.7 engineering profile, 8 October 2026.

Plan descriptions are model-authored proposals. The kernel binds a bounded typed DAG to current spec/policy/candidate, validates required goal/check references and narrows native read/write/read-set capabilities. Only DEPENDS_ON edges determine scheduling; analysis relations are metadata. One active node avoids concurrent writers; CAN_PARALLELIZE is not permission to start workers. Finish stores a node/contract/candidate-bound CAS output labelled MODEL_AUTHORED_UNREVIEWED and sets IMPLEMENTED. It cannot produce VERIFIED. Pending nodes block final delivery; scope revision invalidates the current plan while historical documents remain addressable. Load/backup/restore validate graph/progress/output closure.

Local Ollama uses the same canonical request, durable intent, reservation, tool reply, candidate/review and recovery loop as fixtures. Runtime is operator input, never repo/model authority. The restricted profile requires a literal loopback origin, explicit local-model declaration, bounded context/output/timeout, no credentials/proxy/redirect and denial of known cloud model names. Authority is refreshed immediately before HTTP dispatch. Inference also uses the remaining task active-work deadline; a larger model timeout cannot extend it. Elapsed call time is retained, including interrupted/unknown calls. Canonical request binds model/num_ctx/num_predict; a returned conflicting model blocks with unknown usage. Mandatory protocol/spec/policy/plan is not silently truncated.

Operator-local assertion is not an OS egress proof. The conservative byte estimator is not a provider tokenizer/profile conformance result. Nonstream/thinking-disabled local runtime is a bounded feature; actual installed-model/template/tools acceptance is still required. No real Ollama model was installed/observed in this environment. Fixture/loopback PASS cannot substitute for inference quality.

SQLite schema 2 is unchanged. Optional document fields and new required tool contracts fail closed in older strict decoders; old fixture documents remain readable by 0.7. Remote runtime, streaming, strong verification, full global resource allocation, multiworker mutex, compaction and production release gates remain open. See [ADR 0008](0008-global-token-ledger.md) for store accounting compatibility.
