# ADR 0011: scoped CAS GC, detached owner ve support/vault

Tarih: 9 Ekim 2026. Durum: Implemented engineering slice. Tam lifecycle/privacy/platform release gate değildir.

GC trusted Session/peer-authenticated owner üzerinden çalışır; model tool registry'sine eklenmez. Tam journal, historical document, raw InputRecorded, token/resource receipt, risk assumption, compaction original/history, candidate/check/plan/parent-attempt referansları typed olarak trace edilir. Metindeki hash'ler authority değildir. Journal dışındaki standalone snapshot scope'ları tamamen pin edilir. Pending/UNKNOWN veya active task tüm collector'ı bloke eder. Bounded preview store snapshot/reference digest'ine bağlıdır; collector head'i tekrar denetler. Her nesne size/digest/rooted regular/single-link preflight'tan sonra unlink edilir. Durable intent, per-file receipt ve completion private maintenance namespace'inde kalır; backup bunları korur. Crash sonrası eksik dosya UNLINK kanıtı gibi sunulmaz: ALREADY_ABSENT_AFTER_INTENT ayrı kalır. Task deletion/tombstone/sensitive shared copies/backup purge/restore watermark ayrı C03 işidir.

Detached invocation önce mevcut durable resume admission'ını alır. Aynı invocation ID active/completed aşamada yeniden dispatch yaratmaz; kayıp completion receipt aynı ID ile blind retry'ı reddeder. Detached çalışma client context yerine owner lifetime'a bağlıdır. Background bootstrap aynı absolute executable + fixed argv kullanır, shell/PATH seçimi yoktur; Windows'ta hidden detached process, Unix'te ayrı session. Readiness owner ID/PID/generation ile doğrulanır ve gerçek OS writer lock iki bootstrap yarışını engeller. Quiescent owner-stop endpoint + writer lock kapanışını bekler. SQLite WAL regular/single-link preflight ownership lock'tan sonra yapılır; eski writer'ın checkpoint/unlink kapanışı ile yarışmaz.

Attach retained events için bounded contiguous pages ve distinct current state verir; successful cursor client tarafından saklanır. Idle poll aynı boş state'i tekrar yazmaz. Output backpressure yalnız client'ı durdurur. Ephemeral text delta retained event sayılmaz. Retention gap protokolü/lifecycle deletion ve hostile-principal/orphan-child matrisinin tamamı bu dilimle kabul edilmiş sayılmaz.

Support NUMERIC_ALLOWLIST_SUPPORT_V1 arbitrary string alanları taşımaz. Raw/code/log/task/source/hash/endpoint/model/auth metadata kullanılmaz; bir secret regex'in bütün gizli bilgileri bulacağı varsayılmaz. Collector baş/son snapshot'ını karşılaştırır; ilerlemiş snapshot tutarsız bundle yerine STALE_BASE verir. Normal source changeset export ayrı explicit kullanıcı çıktısıdır.

Unix auth state OS vault'ta saklanan 256-bit key ile AES-GCM şifrelenir. Backend/handle/schema authenticated additional data'dır; decrypted host identity key handle ile yeniden bağlanır. File'da plaintext credential veya local key dosyası yoktur. Eksik/locked vault fallback yaratmaz. Explicit auth migrate-storage eski valid plaintext account state'ini aynı identity ile atomik şifreli kayda taşır; plaintext backup/inference/registration/refresh yoktur. Kayıp key sırasında mevcut profile rotation yeni key uydurmaz. Windows DPAPI değişmez.

Linux helper'sının stdin password ve missing-vs-error behavior'ı [GNOME kaynağında](https://github.com/GNOME/libsecret/blob/main/tool/secret-tool.c), macOS interactive stdin komutu [Apple manpage'inde](https://github.com/apple-oss-distributions/Security/blob/main/SecurityTool/macOS/security.1) doğrulandı. Fixed root-owned/nonwritable system helper, timeout ve bounded secret I/O vardır; key argv/env/log'a girmez. Native desktop vault/unlock kabulü yapılmadan fixture'lar bu sınırı PASS ilan etmez. Admin/same-user malware veya fiziksel disk remnants yokluğu garantisi verilmez.

10 Ekim hardening: executable'ın resolved ancestor dizinleri de root-owned/nonwritable olmak zorundadır; yalnız dosya owner kontrolü writable parent içindeki rename yarışını kapatmaz. Output writer `bytes.Buffer` embed etmez: promoted `ReaderFrom` pipe copy sırasında 512-byte `Write` sınırını atlayabiliyordu. Gerçek 64-KiB stdout/stderr subprocess bu açığı gösterdi ve düzeltmeyi doğrular. Direct helper deadline 10 saniye, pipe drain `WaitDelay` 250 ms; bu bekleme sınırı descendant process-tree fencing/settlement garantisi değildir. Canonical 32-byte key lookup dışındaki sonuçlar reddedilir; error dahil helper key buffer'ları dönüşte temizlenir. Offline locked/missing/invalid-key rotation testi eski ciphertext/account identity'yi korur; gerçek native locked/multi-user kabulü yerine sayılmaz.
